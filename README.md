## Docker 환경에서 실행하기

이 데모 저장소는 소스 코드를 직접 빌드하지 않습니다. 실행에 필요한 게임 파일과 라이브러리는 Docker Hub 이미지에 포함되어 있으므로, 이용자는 Docker 이미지를 내려받아 실행하면 됩니다.

### 1. 사전 준비 사항

- Docker Desktop이 설치되어 있고 실행 중이어야 합니다.
- **Windows**에서는 Windows 11 + WSL2 + WSLg 환경을 권장합니다.
- Windows 10 또는 WSLg가 없는 환경에서는 VcXsrv/Xming 같은 별도 X server 설정이 필요할 수 있습니다.
- **macOS**에서는 별도 설정 없이 `bash scripts/run.sh` 명령만으로 실행할 수 있습니다. 게임은 브라우저를 통해 실행됩니다.

### 2. 실행 방법

#### Windows

Windows 사용자는 PowerShell이 아니라 WSL Ubuntu 터미널 또는 VSCode의 WSL Remote 터미널에서 실행하는 것을 권장합니다.

WSL Ubuntu 터미널 또는 WSL Remote 터미널에서 이 리포지토리를 clone합니다.
그 후 clone 받은 폴더에서 다음 명령어를 실행합니다.

또는 VSCode를 사용하는 경우 원하는 폴더에 먼저 clone 받은 후 Remote Window를 열고 파일-폴더 열기로 clone 받은 폴더를 열 수 있습니다.

```bash
bash scripts/run.sh
```

#### macOS

Docker Desktop을 실행한 뒤, 터미널에서 clone 받은 폴더로 이동하여 아래 명령어를 실행합니다.

```bash
bash scripts/run.sh
```

스크립트가 자동으로 Docker 이미지를 내려받고 브라우저를 열어 게임을 실행합니다.
브라우저가 자동으로 열리지 않는 경우 아래 주소로 직접 접속하세요.

http://localhost:6080/vnc.html?resize=scale&autoconnect=1

> Apple Silicon (M1/M2/M3) Mac을 포함한 모든 Mac 환경을 지원합니다.

### 3. 직접 실행 명령

#### Windows (WSL)

스크립트를 사용하지 않고 직접 실행하려면 WSL 터미널에서 아래 명령을 사용할 수 있습니다.

```bash
docker run -it --rm \
  -e DISPLAY="$DISPLAY" \
  -e WAYLAND_DISPLAY="$WAYLAND_DISPLAY" \
  -e XDG_RUNTIME_DIR="$XDG_RUNTIME_DIR" \
  -v /tmp/.X11-unix:/tmp/.X11-unix \
  -v /mnt/wslg:/mnt/wslg \
  kjhstrange/volcanic_game_img:latest
```

#### macOS

```bash
docker run --platform linux/amd64 --rm \
  -p 6080:6080 \
  본인아이디/volcanic_vnc:latest
```

실행 후 브라우저에서 아래 주소로 접속합니다.

## 게임 안내 및 조작법

### 0. 초기 화면

메인 맵으로 플레이어 건축물과 농장 등 기본 건축물의 위치가 표시됩니다.(기본 건축물은 구현 예정)

상단 바에는 시간, 돈, 경험치/레벨 바, 메뉴가 표시됩니다.
메뉴에 적힌대로 숫자 키 1~5를 눌러 농장/상점/제작/채굴/미니게임 화면으로 전환할 수 있습니다.
같은 숫자 키를 한 번 더 누르면 초기 화면으로 돌아옵니다.

B 키를 눌러 건축 모드로 들어갈 수 있고 우측 상단에 나오는 창에서 원하는 건축 자재를 선택하고
클릭으로 원하는 칸에 배치할 수 있습니다. 우클릭으로 삭제와 Z키로 되돌리기가 있습니다.

### 1. 농장

작물 밭/가축 우리가 각각 5X5 격자로 구현되어 있습니다. 각 칸을 클릭해서 조작할 수 있습니다.
조작에는 작물/가축 구입과 수확이 있습니다.

구입은 상점 화면에서 할 수 있고 농장 화면에서 클릭해서 선택해둔 칸에 구입한 작물/가축이 배치됩니다.
수확은 H키를 눌러 모든 성장한 작물과 생성된 가축의 생산물을 판매할 수 있고, C키를 눌러 선택된 칸만 판매할 수 있습니다.
작물/가축은 성장/생산 단계가 있고 마지막 단계에서만 수확할 수 있습니다.
(gui 출력 구현이 완료되지 않아 단계를 터미널에서 확인해야 합니다.)
(구입/수확이 인벤토리를 거치도록 수정 예정)

수확 대상의 가격은 기본 가치와 품질의 곱으로 정해지고 작물은 해당 칸의 비옥도까지 곱해집니다. 품질, 비옥도는 랜덤 이벤트에 의해 변화합니다.

### 2. 상점

왼쪽 5X5 격자에 인벤토리 아이템이 표시되고 오른쪽 5X5 격자에 상점 아이템이 표시됩니다.
클릭으로 판매/구입됩니다.
현재 작물/가축의 구입만 구현되어 있습니다.

### 3. 제작

왼쪽 5X5 격자에 인벤토리 아이템이 표시되고 인벤토리 아이템을 클릭하면 1개씩 오른쪽 제작 격자에 옮겨집니다.
제작 격자 아래에는 현재 제작 격자에 있는 아이템들로 제작할 수 있는 아이템들과 그 조합식들이 표시됩니다. 조합식 오른쪽의 제작 버튼을 누르면 제작됩니다.

### 4. 채굴

왼쪽 인벤토리 격자에서 곡괭이를 선택할 수 있고 오른쪽 10X10 채굴 격자 중 1칸을 클릭해서 채굴합니다.
각 칸의 광물은 빈 칸/마그마/유황/돌/흑요석/자수정/다이아몬드 중 랜덤으로 1개입니다.

빈 칸과 유황은 곡괭이 없이 채굴할 수 있습니다.
광물은 곡괭이 광물보다 최대 1단계 높은 광물만 채굴할 수 있습니다. 광물 단계는
돌 < 흑요석 < 자수정 < 다이아몬드   입니다.
마그마 칸을 채굴할 경우 곡괭이 내구도가 감소합니다.

R키를 눌러 채굴 격자를 초기화할 수 있습니다.

### 5. 미니게임

미니게임 선택 화면으로 이동합니다. 1~5 미니게임 버튼 중 1개를 클릭해서 실행합니다.
(4, 5번 미구현)

#### AshTyping

타자연습 게임입니다. 게임 화면에서 키보드 입력과 엔터 키만 누르면 됩니다.

#### DinoRun

크롬 공룡게임과 유사한 달리기 게임입니다. 스페이스바/화살표로 조작합니다.

#### MagmaDodge

위에서 떨어지는 마그마 블록을 피하는 게임입니다. WASD로 조작합니다.

### 6. 랜덤 이벤트

모든 랜덤 이벤트는 발생 시 우측 하단에 경고 메시지에 이름과 효과가 출력됩니다.
X 버튼을 누르면 경고창이 닫힙니다.

#### 지진

3초 동안 숫자 키를 통한 화면 이동이 제한됩니다.

#### 화산재

농장의 작물 칸 중 1개에 화산재가 떨어집니다. 해당 칸의 작물 품질이 감소합니다.
일정 시간 후 화산재가 흡수되면 해당 칸의 비옥도가 상승합니다.

#### 화산 가스

농장의 가축 칸 중 1개에 가스가 발생합니다. 해당 칸의 가축 체력과 품질이 감소합니다.
